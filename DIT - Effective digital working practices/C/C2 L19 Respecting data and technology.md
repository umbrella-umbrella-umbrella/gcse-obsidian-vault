# Respecting data and technology

### Data protection
- **Data protection** refers to legal and ethical frameworks that safeguard personal information from unauthorised access, misuse, or breaches.
- A **data subject** is an individual whose personal information is collected, processed, or stored by an organisation. Individuals have rights over their personal data.

### Data protection principles

| Principle | What it means |
| --- | --- |
| Lawful processing | Collect and use data only with a valid legal reason. |
| Purpose limitation | Collect data for a clear purpose and use it only for that purpose. |
| Data minimisation | Collect only the minimum information needed. |
| Accuracy | Keep personal data up to date and correct errors. |
| Storage limitation | Keep data only as long as necessary. |
| Security and confidentiality | Protect data from loss, hacking, or misuse. |
| International transfers | Transfer data only to countries with suitable protection or safeguards. |
| Data subject rights | Respect individuals' rights, including requests to delete data where applicable. |

### Criminal use of computer systems
- Computers, networks, or digital devices can be used as tools for crime, be the target of crime, or both.

| Misuse | Description |
| --- | --- |
| Unauthorised access (hacking) | Accessing a system, network, account, or data without permission, even if nothing is changed. |
| Unauthorised modification | Changing, deleting, or damaging data or software without permission. |
| Creating malware | Designing malicious software to damage systems, steal data, spy on users, disrupt services, or gain access. |
| Spreading malware | Deliberately distributing malware to infect computers or networks. |
| Other criminal use | Unlawfully viewing or stealing data, disrupting systems, or supporting fraud and identity theft. |

- These activities can break privacy laws, damage systems and data, and put people and organisations at risk. The source identifies the UK Computer Misuse Act as one law that covers them.
