# Shared data
- **Shared data** is information passed between two or more systems, organisations, apps, or services rather than kept by just one.
- It may be shared to improve services, coordination, security, or analysis. It may be personal data or service/system data.

### Examples of shared data

| Example | What is shared |
| --- | --- |
| Logging into an app using a Google or Apple account | Account information exchanged between services. |
| Medical records accessed by multiple healthcare providers | Health information shared across providers. |
| Delivery service and partner restaurants | Order details shared to fulfil a delivery. |

### Types of shared data

| Type | Description and example |
| --- | --- |
| Location-based data | Identifies where a device or user is, such as GPS or Wi-Fi location. |
| Cookies | Small files stored by a website to remember preferences or track activity, such as login details. |
| Transactional data | Recorded when a user completes an action, such as an online purchase. |
| Data exchange between services | Data transferred between platforms, such as logging in with Google or Facebook. |

### Responsible handling
- Data should be handled securely, legally, and responsibly, for example according to a privacy policy.
- Users should know who their data is shared with and why.
- Shared data can affect a person's digital footprint: information about them that exists online because of online activity.
- An **active footprint** comes from information deliberately submitted online. A **passive footprint** is collected without the user's knowledge.
