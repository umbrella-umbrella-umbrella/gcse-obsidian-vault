# Hacking
- **Hacking** means gaining unauthorised access to a computer system, network, or data.
- Hacking can be harmful, neutral, or beneficial, such as finding vulnerabilities so security can be improved.

### Types of hackers

| Type | Purpose or behaviour |
| --- | --- |
| White hat | Works to improve security by finding and fixing vulnerabilities. |
| Black hat | Exploits systems for personal gain, crime, or malicious purposes. |
| Grey hat | Explores systems and identifies flaws, sometimes without permission. |

### Ethical hacking and penetration testing
- **Ethical hacking** deliberately tests systems with permission to find weaknesses before malicious hackers exploit them.
- **Penetration testing** evaluates IT security by simulating a cyber attack using ethical hackers.

| What testing can help with | Characteristics of a test |
| --- | --- |
| Identify weak points and reduce risks of unauthorised access and data breaches. | It is authorised and done with full permission. |
| Identify possible DoS exploits and vulnerabilities that malware could use. | The goal is to identify and fix vulnerabilities, not exploit them. |
| Strengthen defences and protect data. | Ethical hackers follow agreed rules, laws, and professional codes of conduct. |
