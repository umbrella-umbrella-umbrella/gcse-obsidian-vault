# Network
- A network is a system where two or more devices (such as computers, phones, servers, or printers) are connected so they can communicate, share resources, and exchange data.
### Ad hoc network
- Ad hoc networks are temporary networks created without a central router or access point.
### Types of networks
- Wi-Fi Network
- Cellular Network

# Network Security

### Security Issues
- **Security issues** threaten safety and privacy of data, especially the use of open networks.

### Open networks are vulnerable because data is unencrypted: 
- Eavesdropping: Others can intercept data sent over the network. 
- Man-in-the-middle attacks: Hackers can intercept or modify communications. 
- Malware distribution: Devices can be infected by malicious users on the same network.
- Unauthorised access: Any device can connect without authentication, potentially accessing shared files.

### Mitigation strategies: 
- Use a VPN when connected to open Wi-Fi. 
- Avoid sensitive transactions (banking, passwords) on open networks. 
- Enable firewalls and security software.

### Using public Wi-Fi at a café, airport, or hotel 
- Public Wi-Fi is convenient but often not secure, hackers can intercept data sent over the network. 
- A VPN (Virtual Private Network) encrypts your internet traffic, making it unreadable to others on the same network

# Network Performance

### Performance Issues
- Performance issues affect the speed, reliability, and usability of the network and in particular, ad hoc networks

### Ad hoc networks often have limited performance compared to traditional networks: 
- Limited range: Wi-Fi hotspots only cover a small area. 
- Shared bandwidth: Multiple devices using the same connection can slow speeds. 
- Interference: Other wireless devices (microwaves, Bluetooth, nearby networks) can reduce performance. 
- Device dependency: If the host device (e.g., smartphone) moves or loses power, the network is disrupted.

Impact on digital devices 
- Mobile hotspots drain battery life faster. 
- You may use up the monthly data limit. 
- Difficult to monitor signal strength
