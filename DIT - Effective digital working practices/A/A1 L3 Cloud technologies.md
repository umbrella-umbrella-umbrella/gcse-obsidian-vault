# Cloud Technologies
- Cloud Systems are software, and data that are stored and run over the internet on the provider's servers

| Cloud System features    | Explanation                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------- |
| Device Sync              | Keeping files, apps, or settings the same across multiple<br>devices.                             |
| Online / Offline working | Being able to work with or without an internet connection, with changes syncing when back online. |
| Notifications            | Real-time alerts across devices to keep users updated                                             |
