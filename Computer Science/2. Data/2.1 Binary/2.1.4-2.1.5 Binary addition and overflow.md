# 2.1.4-2.1.5 Binary addition and overflow

### Adding in binary

One of the most common operations that you will need to carry out is adding binary numbers together. The method you will use is the same method you may have been taught to add denary numbers when you were younger: column addition.

### Golden rules

| Addition | Result bit | Carry bit |
|---|---:|---:|
| 0 + 0 | 0 | 0 |
| 0 + 1 | 1 | 0 |
| 1 + 1 | 0 | 1 |
| 1 + 1 + 1 | 1 | 1 |

### Binary addition

Add the bits in each column from right to left. If a column totals 2, write 0 and carry 1; if it totals 3, write 1 and carry 1.

```text
  0001  (1)
+ 0101  (5)
------
  0110  (6)
```

When a carry enters a column that contains two 1s, add all three bits: `1 + 1 + 1 = 3`, so write 1 and carry 1.

### Overflow example

In an 8-bit calculation, adding two large values can produce a ninth bit:

```text
  11001111
+ 01110100
----------
1 01000011
```

The final carry lies outside the 8-bit space. What happens to it depends on how the computer or program handles overflow.

### Overflow

What you've just seen is called overflow. It means the result of the calculation is too large for the space allocated (in this case 1 byte). The way a computer handles this will depend on how it's setup.

- It could crash and report an overflow error.
- It could truncate the answer (simply leave off the extra one).
- It could wrap the number around back to zero.

### Handling overflow in a manual calculation

When showing an 8-bit addition that produces a carry beyond the available space, make the overflow clear by writing the extra carry separately:

```text
    1   (overflow carry)
  11001111
+ 01110100
----------
1 01000011
```

The 8-bit result is `00100011`, with an additional carry of 1.

### In programming…

Python is a language that is flexible with storage space. Integers are not limited to a specific number of bits and can expand to fit available memory. In some applications, it's important to work out how much space is ‘just enough', particularly when memory might be short. Such applications include embedded systems where the hardware is basic.
