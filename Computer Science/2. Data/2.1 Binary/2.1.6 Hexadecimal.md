# 2.1.6 Hexadecimal

### Quick test!

Copy down this number. You have 5 seconds! Did you get it all down correctly?

### Human problems

That was difficult, wasn't it? Did you get all of the digits correct? Even if you had more than 5 seconds, chances are you'd make a mistake. This is because people find binary numbers hard to read, write and understand.

An alternative solution Computer scientists often use an alternative method of representing long binary numbers. This is known as hexadecimal. Hexadecimal is a number system that is base 16.

### Conversion

You can convert easily between binary and hexadecimal by splitting the binary number into nibbles.

`0            1  1          0  1  1  0                                                          0`

You convert each nibble into denary and then into one hexadecimal digit. 4+2=6               8 + 4 = 12 = C So the hexadecimal is 6C.

### Conversion

Going from hexadecimal to binary is just as straightforward. We take the hexadecimal, split it into its digits and convert these to decimal and then into binary nibbles.
