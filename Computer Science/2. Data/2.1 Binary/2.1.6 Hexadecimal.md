### Human problems

People can find long binary numbers difficult to read, write and understand. **Hexadecimal** is a base-16 number system that provides a more compact way to represent binary values. Each hexadecimal digit represents one 4-bit nibble.

| Hexadecimal | Denary | 4-bit binary |
|---:|---:|---|
| 0 | 0 | `0000` |
| 1 | 1 | `0001` |
| 2 | 2 | `0010` |
| 3 | 3 | `0011` |
| 4 | 4 | `0100` |
| 5 | 5 | `0101` |
| 6 | 6 | `0110` |
| 7 | 7 | `0111` |
| 8 | 8 | `1000` |
| 9 | 9 | `1001` |
| A | 10 | `1010` |
| B | 11 | `1011` |
| C | 12 | `1100` |
| D | 13 | `1101` |
| E | 14 | `1110` |
| F | 15 | `1111` |

For example, `1010`₂ = 10₁₀ = A₁₆, and `1111`₂ = 15₁₀ = F₁₆.

### Converting binary to hexadecimal

Split the binary number into 4-bit nibbles, then convert each nibble to one hexadecimal digit.

```text
0110 1100₂
  6    C
```

Therefore, `01101100`₂ = `6C`₁₆. The first nibble is 6; the second is 8 + 4 = 12, which is C.

### Converting hexadecimal to binary

Convert each hexadecimal digit into its 4-bit binary equivalent. For example, `BE`₁₆ has digits B = 11 and E = 14:

```text
B     E
1011  1110
```

Therefore, `BE`₁₆ = `10111110`₂.
