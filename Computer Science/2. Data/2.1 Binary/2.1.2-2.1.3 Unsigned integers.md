# 2.1.2-2.1.3 Unsigned integers

### Numbers

Humans count using denary (base 10), which uses the digits 0 to 9. Each column is a power of 10. For example, 5049 can be expanded as follows:

| Place value | 10³ | 10² | 10¹ | 10⁰ |
|---|---:|---:|---:|---:|
| Column value | 1000 | 100 | 10 | 1 |
| Digit in 5049 | 5 | 0 | 4 | 9 |
| Contribution | 5000 | 0 | 40 | 9 |

So, 5049 = 5000 + 0 + 40 + 9.

### Binary place values

Computers use binary (base 2), with the symbols 0 and 1. Each column is a power of 2. For example, `1101` is:

| Place value | 2³ | 2² | 2¹ | 2⁰ |
|---|---:|---:|---:|---:|
| Column value | 8 | 4 | 2 | 1 |
| Bit | 1 | 1 | 0 | 1 |
| Contribution | 8 | 4 | 0 | 1 |

Therefore, `1101`₂ = 8 + 4 + 0 + 1 = **13** in denary.

### Counting

A 4-bit pattern has 2⁴ = 16 possible values, from 0 to 15. The patterns count in order from `0000` to `1111`.

### Nibbles

A **nibble** is a set of 4 bits. It can represent 16 values (2⁴), from 0 to 15. For example, `0110` is 4 + 2 = **6**:

| Place value | 8 | 4 | 2 | 1 |
|---|---:|---:|---:|---:|
| Bit | 0 | 1 | 1 | 0 |

To convert 13 from denary to binary, choose the place values that add up to 13:

- 13 − 8 = 5, so put 1 in the 8 column.
- 5 − 4 = 1, so put 1 in the 4 column.
- Put 0 in the 2 column and 1 in the 1 column.

Therefore, 13 = `1101`₂.

### Bytes

Two nibbles make a **byte**, which is 8 bits. A byte can represent 256 values (0 to 255) when unsigned. For example:

| Place value | 128 | 64 | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Bit | 1 | 0 | 0 | 0 | 0 | 1 | 1 | 0 |

The value is 128 + 4 + 2 = **134**.

### Most significant bit

Binary patterns are written from the largest place value to the smallest. The **most significant bit (MSB)** is the leftmost bit, which has the largest place value. For example, in `10001100`, the MSB has a place value of 128.
