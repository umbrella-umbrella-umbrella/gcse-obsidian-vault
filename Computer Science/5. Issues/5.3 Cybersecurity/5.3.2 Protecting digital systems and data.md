# 5.3.2 Protecting digital systems and data

## Anti-malware software

**Anti-malware software** detects, quarantines and removes potentially damaging programs. It can scan files as they enter a computer system and compare them with information about known malicious code. If it finds a problem, it can quarantine the file so it cannot affect the system, notify the user, and allow the file to be deleted or reviewed.

Anti-malware relies on information about malicious programs. New malware is created continually and may not be recognised by out-of-date protection. Anti-malware software should be kept up to date so it can identify known threats reliably.

## Encryption

**Encryption** converts data into a scrambled, unreadable form. It helps protect sensitive data when it is stored or transmitted. An unauthorised person may still access or intercept the data, but should not be able to understand it without the means to decrypt it.

## Backup and recovery

A **backup** is a copy of data stored separately from the original, for example in cloud storage. Backups should be automated where possible and performed regularly. Critical data may need to be backed up hourly or daily.

**Recovery** is the process of using a backup copy to restore a database or system to the correct state after a failure. Backups are useful only if suitable copies exist and can be restored.

## Access control

**Access control** gives users different levels of access to systems. Users should only be given access to the software, data and hardware they need. This is the **principle of least privilege**. It limits the damage users can cause accidentally or deliberately.

## Firewalls

A **firewall** monitors and controls incoming and outgoing network connections, blocking connections that are not allowed. Firewall software may run on a computer or, in a large network, on dedicated hardware. It can block unauthorised access attempts from outside the network and may limit outgoing traffic if an attacker has already gained access through another route.

## Acceptable Use Policies

An **Acceptable Use Policy (AUP)** is a set of rules and procedures users must follow to help protect an organisation’s systems and networks. Training can reinforce the rules and help reduce mistakes that social engineering attacks rely on.

AUP rules may include:

- Limiting internet access
- Preventing unauthorised downloads and software installation
- Restricting the use of external storage devices such as USB drives
- Training users to recognise phishing messages
- Using multi-factor authentication
- Training users not to disclose confidential information over the phone
- Preventing confidential files from being removed from the premises

## Physical security

Physical security helps prevent equipment and data from being stolen, mishandled or damaged. Measures include:

- Locks and secure locations for hardware
- CCTV
- Fire detection and suppression systems
- Biometric access controls
