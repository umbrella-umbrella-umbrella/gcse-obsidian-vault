# 3.2.2 Utility Software

### Utility software

- Previously you have learned that there are two types of software - systems and applications. Operating systems are a type of systems software.
- Utility software is another type of system software, that:
- adds functionality to a computer, improves its performance, or helps maintain its hardware or other software
- performs a specific management task such as backup and recovery, disk clean up, compression or archiving.

### Research task

- Your first activity today is to research some of the tools that are available to perform utility tasks.
- There are a huge array of free and proprietary tools for performing these tasks.
- The types of utility program you need to research are:
- file repair/recovery software
- backup/recovery software
- file compression software
- disk defragmentation software.

### Choosing the right tool for the job

- It's important to select the right tool for the job. This is as true in computing as it is in life!
- You may need to select a utility program for a particular situation and explain why it is necessary.
- A laptop has starting running slowly. It takes a long time to open files so that they can be worked on. Identify and justify a utility software program to use in this case.
- Disk defragmentation might be necessary to move all of the files into contiguous storage on the hard disk in order to speed up access.
