 An embedded computer is usually a simple computer, responsible for a dedicated task.
- Characteristics Include
	- Responsive to their environment
	- Task Specific
	- Low power consumption
	- Small Physical Size
	- Low maintenance
	- Low cost
- Hardware in an Embedded System
	- The physical components that you can see / touch in an embedded system
	- (e.g.) Fitness Tracker
            Heart rate monitor
			- Accelerometer
			- Battery
			- GPS
- Software in an Embedded System
	 - Generally embedded systems have a small storage device to store their simple programs, these will be short and simple.
	- This means that the programs written for these embedded systems are very small and are do not need to be modified once installed - This is knows as **Firmware**
