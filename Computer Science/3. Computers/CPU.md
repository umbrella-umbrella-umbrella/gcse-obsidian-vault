**Purpose of the CPU**
- To process data and instructions  and control the rest of the computer system

- **Buses:**
	- *Data Bus*
		- Carries the actual data between the processor and other components
	- *Address Bus*
		- Carries Memory *Addresses* from the processor to other components such as RAM
	- *Control Bus*
		- Carries control signals from the processor to other components
