## Von Neumann Architecture
- *Nearly every modern-day computer uses this Architecture pioneered by Von Neumann, they are made of:*
	- A processing unit that contains an ALU and **processors registers**
	- A control unit that contains an **instruction register** and program counter register
	- memory that stores both data and instructions
	- external data storage
	- input and output mechanisms
