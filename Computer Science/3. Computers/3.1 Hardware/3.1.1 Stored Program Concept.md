## Von Neumann Architecture
- *Nearly every modern-day computer uses this Architecture pioneered by Von Neumann, they are made of:*
	- A processing unit that contains an ALU and **processors registers**
	- A control unit that contains an **instruction register** and program counter register
	- memory that stores both data and instructions
	- external data storage
	- input and output mechanisms

# Central Processing Unit
- Commonly referred to as the CPU, it is the "brain of the computer"
- It is the hardware component which is responsible for all the processing that a computer carries out - its job is to process data.
	- ### Control Unit
		- It receives signals from other parts of the computer system and sends signals to them
		- It is responsible for:
			- Handling hardware inputs
			- For fetching, decoding and executing.
		- It has the most responsibility in the CPU
	- ### Arithmetic Logic Unit (ALU)
		- It performs operations on data, such such as +, /, =, \*, AND, NOT, OR, et.c
		- It it is able to
			- Compare numbers to **0**
			- Test if two numbers are **equal**
		- It uses logic gates in combination to perform operations
	- ### Registers
		- Also known as *immediate access storage* 
		- They are a type of memory that are **extremely** fast, much faster than the RAM
		- Each type of processor has different registers that are designed to hold different information.
		- Most processors have
			- An **Instruction Register**
				- Holds instructions currently being executed by the CPU
			- An **Accumulator**
				- Holds the accumulated result of operations carried out by the ALU
			- A **Program Counter**
				- Holds the memory address of the next instruction to be executed
	- ### Clock Chip
		- This determines the speed of the CPU
		- It uses a vibrating crystal that maintains a constant rate of vibration
		- The speed of it is measured in Hertz (Hz) which is the amounts of cycles per second (500Hz = 500cycles per seconds, Current computers have Clock Speeds of 3GHz = 3 billion cycles per second)
		- Each "tick" is a part of the FDE Cycle
	- ### Pipelining
		- Each instruction that is carried out has several stages (F,D,E) Each component of the CPU has a different job to do in this cycle.
		- Sometimes a component has nothing to do whilst it is waiting for the component before it in the sequence to complete its task, which **increases overall processing time needed.**
		- **Pipelining** is a method of keeping all the components busy as to improve overall CPU performance.
		- A CPU is "fully pipelined" if an instruction can be fetched every clock cycle

	- ## **Fetch, Decode, Execute (FDE)**
		- The CPU follows three steps in order to process data known as the fetch-decode-execute cycle.
		- Whenever you open and work with a program its data + instructions are loaded into your computer's RAM
			- ***Fetch***
				- In this step the CPU fetches data from the **RAM** (main memory) and then stores it in its own ultra-fast memory known as **Registers**
				- For this to happen the CPU uses a hardware path known as the **address bus*** 
					- The memory address of the next item that the CPU wants is put onto the address bus. 
					- Data from this memory address then travels from the RAM to the CPU on another hardware path called the **data bus.**
			- ***Decode***
				- Decode = working out what the instruction it has just fetched actually means
				- The **control unit** decodes the instruction by looking it up in the instruction set.
				  *Instruction Set = the full list of operations that a microprocessor can carry out.*
			- ***Execute***
				- When Data Processing happens
				- Instructions are carried out on the data, some are carried by the ALU (adding, shifting, AND, OR et.c)
				
		- Once a FDE cycle is complete another begins.
				
		- **Buses:**
		    - _Data Bus_
		        - Carries the actual data between the processor and other components
		    - _Address Bus_
		        - Carries Memory _Addresses_ from the processor to other components such as RAM
		    - _Control Bus_
		        - Carries control signals from the processor to other components
		
		***Summary of FDE:***
		- Instructions and data are stored in the memory. (Initially)
		- Instructions are fetched one at a time into the processor. (Fetch)
		- The instructions are decoded by the control unit. (Decode)
		- The instructions are executed, sometimes using the arithmetic logic unit. (Execute)
