# 3.1.1 Fetch Decode Execute - Part 2

### Recap

Instructions and data are stored in memory. Instructions are fetched one at a time into the processor. The instructions are decoded by the control unit. The instructions are executed, sometimes using the arithmetic logic unit. The Central Processing Unit (CPU) contains the Arithmetic/Logic Unit (ALU), Control Unit (CU) and registers. Clock speed determines processor performance, i.e. the number of instructions per second. Pipelining improves performance by overlapping parts of the fetch-decode-execute (F-D-E) cycle for multiple instructions.

### Instructions and data

In a computer everything is represented in binary. This includes the instructions that the CPU needs to carry out. Instructions and data are stored in RAM until they are needed by the CPU. Each instruction and item of data is stored in a location in memory. Each element of the memory has a unique address. This means that each instruction has an address. The first memory element that contains the instruction is the address of that instruction.

### Buses

The CPU connects to other components through buses, which carry multiple bits at once.

| Bus | Purpose | Example |
|---|---|---|
| Data bus | Carries data between components. | Transfers an instruction from RAM to the CPU. |
| Control bus | Carries control and status signals between the CPU and other components. | Signals a component to start an operation. |
| Address bus | Carries the address of a memory location or device. | Carries the address of an instruction being fetched. |

### Directionality of buses

In the simple model of the computer discussed in these lessons, each of the three buses has directionality. The control bus is bidirectional – it needs to carry status information to devices and to carry the status information signals that devices send back. The data bus is bidirectional – two-way data transfer is required when reading and writing data to memory. The address bus is unidirectional – the CPU can point to addresses in memory or to other devices, however those hardware components cannot point to an address in the CPU. You will see this directionality represented in diagrams as single-ended or double-ended arrows.

### Address bus

Do you know the difference between a 32-bit and a 64-bit CPU? 32-bit processors are cheaper, but can only use a limited amount of RAM. The ‘bandwidth' of these CPUs relates to the size of the address bus. It refers to the number of unique memory addresses that can be accessed. Let's look at this in more detail, using the example of a simplified CPU with a low bandwidth.

### Address bus

Consider a CPU with a 4-bit bandwidth (address bus). How many unique memory addresses can it access? 4-bit addresses range from 0000 to 1111 inclusive. 1111 in denary is 15 (plus 1 because we must include 0), which gives 16 addresses. 16 addresses is 24. Remember the formula to find the number of patterns in any number of bits: 2n This formula works for finding the maximum number of memory addresses as well.

### Primary storage (memory)

A 32-bit CPU can access 4,294,967,296 unique memory locations. Each memory location consists of a row of cells. Let's consider a situation where the row is 8 cells long. Each of the 4,294,967,296 addresses points to a row of 8 bits (1 byte). Therefore, a 32-bit address bus can address up to 4 GiB when each address stores one byte (4,294,967,296 bytes). For example:

| Address | Contents |
|---|---|
| `00001011` | `01000100` |
| `00001010` | `01000011` |
| `00001001` | `01000010` |
| `00001000` | `01000001` |

### Memory (RAM)

Random Access Memory (RAM) is volatile memory – this means that its contents are erased when its power supply is turned off. RAM is often referred to as ‘primary storage', as it sits close to the CPU. However, it isn't possible to keep a computer on permanently. So it is necessary to have somewhere to store the programs and data (that make a computer general purpose) when the power is switched off. The non-volatile storage required for this job is most often a hard disk. Hard disks are often referred to as ‘secondary storage', to make them distinct from ‘primary storage'.
