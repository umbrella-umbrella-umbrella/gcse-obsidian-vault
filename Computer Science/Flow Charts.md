# Flow Charts 
- A flow chart is a design tool that shows the steps in a process or system using symbols, shapes, and arrows to illustrate the flow of information, tasks, or decisions.

| Advantages                                                                                                                               | Disadvantages                                                                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <br>- Visual representation makes complex processes easier to understand.<br>    <br>- Standard symbols provide clarity and consistency. | - Can become very complex for large processes.<br>    <br>- Time-consuming to create and update for complicated systems.<br>    <br>- Requires knowledge of standard symbols to interpret correctly. |

### Examples of Use
- A programmer could use a flow chart to help solve a problem.
- A flowchart provides a visual representation that will help them write the correct code for an IT system.
